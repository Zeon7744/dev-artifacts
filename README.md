## 简介

开发工具箱，集成多个 MCP Server，涵盖金融新闻、短剧创作、投资分析、加密货币预测等场景。

## 集成模块

| 模块 | 描述 |
|------|------|
| financial-news-mcp | 财经新闻数据 |
| short-drama-mcp | 短剧创作辅助 |
| investment-mcp | 投资分析工具 |
| crypto-mlp | 加密货币预测 |
| commodity-mlp | 大宗商品预测 |

## 快速开始

```bash
git clone https://github.com/Zeon7744/dev-artifacts.git
cd dev-artifacts
```
