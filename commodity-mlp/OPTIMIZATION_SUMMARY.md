## 关键优化点

### 1. 数据生成改进
- 加入趋势成分（长期趋势方向）
- 加入波动聚集（GARCH-like效应）
- 使用工作日频率（更真实）

### 2. 高级版模型特性
- **集成学习**: 3个不同配置的MLP软投票
- **时序交叉验证**: 5折TimeSeriesSplit，模拟真实交易
- **特征选择**: 自动选择Top-20显著特征
- **置信度过滤**: 保守/激进两种交易模式

### 3. 回测引擎改进
- 支持np.ndarray和pd.Series输入
- 完整的交易成本计算
- 最大回撤和夏普比率评估

## 使用方法

```bash
# 原版分析
python cli.py --all

# 优化版分析
python cli.py --all --optimize

# 高级版分析（推荐用于真实数据）
python cli.py --all --advanced

# 单商品详细分析
python cli.py --symbols GC=F --advanced --verbose
```
