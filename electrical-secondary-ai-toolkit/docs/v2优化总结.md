## 🚀 快速使用

### 运行完整工作流
```bash
cd electrical-secondary-ai-toolkit
pip install -r requirements.txt
python3 scripts/run_workflow_v2.py
```

### 生成指定类型措施单
```bash
python3 scripts/05_measures_generation_v2.py \
  --input examples/example_220kV_transformer.json \
  --output docs/output.json \
  --validate \
  --templates data/templates_附录4-6_v2.json
```

### 启动API服务
```bash
python3 api_server.py
# 访问 http://localhost:8000/docs
```
