## 新增模块

### 1. RAG知识库模块 (tools/rag/)

| 文件 | 功能 | 大小 |
|------|------|------|
| vector_store.py | 向量存储适配器 (ChromaDB + JSON降级) | 7.6KB |
| document_loader.py | 文档加载器 (PDF/Markdown/JSON) | 6.2KB |
| chunker.py | 智能分块器 (金融报告专用) | 8.8KB |
| embedder.py | 嵌入模型 (本地 + 哈希降级) | 4.8KB |
| knowledge_base.py | 知识库管理 | 9.5KB |

**特性**:
- 支持PDF/Markdown/JSON文档加载
- 金融报告专用智能分块
- 本地向量存储 (ChromaDB优先，JSON降级)
- 语义搜索 + 元数据过滤

### 2. Agent工作流模块 (agents/)

| 文件 | 功能 | 大小 |
|------|------|------|
| base_agent.py | Agent基类 (重试/超时/上下文) | 5.3KB |
| analyst_agent.py | 分析师Agent (每日简报) | 10.4KB |
| watcher_agent.py | 监控Agent (异常预警) | 8.6KB |
| reporter_agent.py | 报告Agent (多格式输出) | 9.5KB |
| orchestrator.py | 编排器 (串行/并行工作流) | 6.6KB |

**工作流**:
- `daily_briefing`: 每日简报自动生成
- `monitoring`: 异常监控实时推送
- `report`: 多格式报告输出 (markdown/json/html/csv)

### 3. 本地LLM集成 (llm_providers/)

| 文件 | 功能 | 大小 |
|------|------|------|
| base_provider.py | Provider抽象接口 | 2.7KB |
| ollama_provider.py | Ollama本地LLM支持 | 10.3KB |
| openai_provider.py | OpenAI API备用 | 7.9KB |
| provider_factory.py | 动态Provider选择器 | 9.7KB |

**特性**:
- Ollama本地模型优先
- OpenAI API自动降级
- Provider熔断器机制
- 可用模型列表查询
