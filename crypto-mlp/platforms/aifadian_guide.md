### 项目介绍

```markdown
## 项目简介

本系统是一个高精度的加密货币价格预测分析工具，采用五模型投票集成机制（RF+GB+MLP+LR+SVM），结合自适应权重调整和置信度校准算法，显著提升了预测准确性和可靠性。

### 核心亮点

- **CV准确率**: 92.94%（原版仅49.14%）
- **预测置信度**: 91.2%（突破90%阈值）
- **模型集成**: 5个经典机器学习模型协同决策
- **自适应降权**: 低置信模型自动降低权重
- **风险管理**: Kelly公式仓位管理 + 多层熔断机制
- **完整测试**: 7/7项自动化测试通过

### 技术栈

- Python 3.8+
- scikit-learn
- pandas, numpy
- matplotlib
- optuna（超参数优化）
- yfinance / binance API

### 使用场景

- 量化交易策略开发
- 风险管理研究
- 机器学习教学演示
- 学术研究参考
```
